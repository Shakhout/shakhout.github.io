01 — About

Owning features end to end, from schema to screen.

I'm a Senior Full-Stack Developer based in München with more than ten years of professional Agile software development. Since 2018 I've been at AlfaDocs, taking full ownership of features across a production SaaS platform.

I work with Domain-Driven Design and Test-Driven Development, and care about clean architecture, RESTful API design, performance and application security. Day to day that means PHP 8 and Symfony, Java and Spring Boot, Node.js, and React with Redux and TypeScript on the front end, shipped through Docker, Kubernetes, AWS and GitLab CI.

Lately I've been building AI tooling into the workflow — including a production error-fixing agent that analyses server errors, opens pull requests and files Jira tickets on its own.
